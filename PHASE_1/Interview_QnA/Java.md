# Java Basics — Q&A

## Question 1: Why does Java have a coffee cup symbol/logo?

**Answer:**

> Java was originally called "Oak", but that name was already trademarked. The team renamed it "Java", inspired by Java coffee from Indonesia, and used a coffee cup as the logo to match the theme.

---

## Question 2: What is Java — is it a programming language, a platform, or both?

**Answer:**

Java is **both** a programming language and a platform.

| Aspect | Description |
|---|---|
| As a **Language** | We write code using its syntax and rules. |
| As a **Platform** | It provides the JVM, which allows that code to run on any operating system without changes. |
